# docs/ - 项目文档

## 目录简介

perf-hunter 的内部文档，包含设计文档、任务追踪、讨论记录等。

## 子目录结构

### meta/
项目元信息文档：
- `project-structure.md` - 完整目录结构说明

### module/<name>/
按模块组织的文档：
- `how/` - 架构与机制设计
- `what/` - 接口规范与说明

### system/
系统级文档：
- `how/` - 流程与方法论

### task/
任务管理：
- `active/` - 进行中任务
- `backlog/` - 待办任务

### discussion/
设计讨论记录

## 重要文档

- `CHANGELOG.md` - 版本变更日志
- `agents.md` - AI Agent 配置
- `TODO_BUGFIX_*.md` - Bug 修复待办

## 文档维护

新增文档需同步更新 `meta/project-structure.md`
