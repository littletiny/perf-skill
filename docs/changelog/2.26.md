# Version 2.26 - 调整 event 格式

## 变更摘要

将 cluster-comm 和 get-comm-top 的 event 格式从 `<EVENT:value>` 改为 `EVENT(value)`。

## 变更详情

| 命令 | 旧格式 | 新格式 |
|------|--------|--------|
| cluster-comm | `<HIGH_KERNEL_RATIO:94.9%>` | `HIGH_KERNEL_RATIO(94.9%)` |
| cluster-comm | `<MANY_SMALL_PROCESSES:5p/0.50%>` | `MANY_SMALL_PROCESSES(5p/0.50%)` |
| get-comm-top | `<HIGH_KERNEL_RATIO:94.9%>` | `HIGH_KERNEL_RATIO(94.9%)` |
| get-comm-top | `<MANY_SMALL_PROCESSES:5p/0.50%>` | `MANY_SMALL_PROCESSES(5p/0.50%)` |

## 文件变更

- `scripts/perf_toolkit/analysis/comm_clusters.py`
- `scripts/perf_toolkit/analysis/comm_top.py`
