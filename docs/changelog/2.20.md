# Changelog 2.20

## get-process-top 输出格式变更

### 变更内容
- 单个进程的输出格式从 `comm pid=PID cpu=X% kernel=Y%` 改为 `comm(PID) total_util/kernel_util`
- 新增 header 行描述格式: `# Format: comm(pid) total_util/kernel_util`

### 变更理由
- 更紧凑的格式，便于快速阅读
- 符合 `comm(pid)` 的常见进程标识惯例
- 直接显示 kernel 利用率而非比例，更直观

### 影响范围
- 仅影响文本模式输出 (`--format text`)
- JSON 模式输出保持不变

### 示例

**变更前:**
```
nginx pid=1234 cpu=45.50% kernel=12.30%
redis pid=5678 cpu=23.40% kernel=5.60%
```

**变更后:**
```
# Format: comm(pid) total_util/kernel_util
nginx(1234) 45.50%/12.30%
redis(5678) 23.40%/5.60%
```
