# Version 2.24 - 模板化输出系统重构

## 变更摘要

重构了文本输出系统，将原本集中式的格式化逻辑解耦为模板化架构。

## 问题背景

之前的架构问题：
- `text_output_adapter.py` 是一个巨大的 if/elif 分发器（~400 行）
- 添加新 command 需要修改 adapter
- 修改输出格式需要修改 adapter
- 数据模型和格式化逻辑分离，违反内聚性原则

## 解决方案

### 1. 引入 TemplateConfig 配置类

在 `output_models.py` 中定义模板配置：

```python
@dataclass
class TemplateConfig:
    template_type: str  # "simple_list" | "key_value" | "table" | "nested" | "custom"
    list_field: Optional[str] = None      # 数据列表字段名
    header: Optional[str] = None          # 表头描述
    display_fields: List[str] = field(default_factory=list)  # 显示字段
    index_format: Optional[str] = None    # 序号格式
    custom_renderer: Optional[str] = None # 自定义渲染器标识
    empty_message: Optional[str] = None   # 空列表提示
```

### 2. 为每个 Output 类配置模板

将模板配置内嵌到 Output 模型中：

```python
@dataclass
class HotspotsOutput(BaseOutput):
    hotspots: List[HotspotItem] = field(default_factory=list)
    
    def __init__(self, ...):
        ...
        self._template_config = TemplateConfig(
            template_type="simple_list",
            list_field="hotspots",
            header="# index,funcname,self,inclusive",
            display_fields=["symbol", "self", "inclusive"],
            index_format="#{index}",
            empty_message="No hotspots found"
        )
```

### 3. 实现 5 类模板渲染器

| 模板类型 | 适用命令 | 示例输出 |
|---------|---------|---------|
| `simple_list` | hotspots, processes, cores | `#1 func 15% 45%` |
| `key_value` | clusters, comm_groups | `EVENT_LOCK 7.5%` |
| `table` | anomalies, windows | `SPIKE cpu=0 time=...` |
| `nested` | traces | `>>> target (20%)\n  #1 [5%] caller` |
| `custom` | bottleneck, cpu_usage | `Verdict: HEALTHY` |

## 带来的好处

1. **添加新 command**: 只需在 model 中指定 `template` 和 `template_config`，无需修改 adapter
2. **修改格式**: 改模板类一处，所有使用它的命令自动生效
3. **新增模板类型**: 实现 Template 接口，其他命令可复用
4. **代码精简**: `text_output_adapter.py` 从 ~400 行降到 ~300 行，且结构更清晰
5. **单一职责**: 每个模板类只负责一种渲染逻辑

## 兼容性

- 所有现有 command 无需修改即可正常工作
- 输出格式与之前完全一致
