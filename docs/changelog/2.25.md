# Version 2.25 - 统一显示格式配置

## 变更摘要

将所有命令的显示格式配置（header、empty_message、截断提示等）集中到一个文件管理。

## 问题背景

v2.24 虽然引入了模板系统，但配置仍然分散：
- `header`, `empty_message` 分散在 `output_models.py` 的 15 个类中
- 截断提示的 `field_map` 在 `text_output_adapter.py` 中

**目标**：修改显示格式只需改一个文件。

## 解决方案

### 1. 新建 display_presets.py

集中定义所有命令的显示格式配置：

```python
DISPLAY_PRESETS = {
    "hotspots": {
        "template_type": "simple_list",
        "header": "# index,funcname,self,inclusive",
        "empty_message": "No hotspots found",
        "total_field": "total_hotspots",      # 用于截断提示
        "shown_field": "shown_hotspots",
    },
    "processes": { ... },
    # ... 其他命令
}
```

### 2. 简化 Output 类

从分散配置改为引用 preset：

```python
# Before
self._template_config = TemplateConfig(
    template_type="simple_list",
    header="# index,funcname,self,inclusive",
    empty_message="No hotspots found",
    # ... 还要配置截断字段
)

# After
self._template_config = TemplateConfig.from_preset("hotspots")
```

### 3. 统一截断逻辑

`text_output_adapter.py` 不再硬编码 `field_map`，而是从 `TemplateConfig` 读取 `total_field` 和 `shown_field`。

## 带来的好处

1. **单一文件管理**：所有显示配置在 `display_presets.py`
2. **修改一处生效**：改 header 格式只需改 presets
3. **新增命令更简单**：在 presets 加一行配置即可
4. **Output 类更简洁**：从 ~15 行配置代码降到 1 行
