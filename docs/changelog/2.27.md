# Version 2.27 - 彻底解耦命令与格式化逻辑

## 问题修复

修复了 anomalies 和 path_clusters 命令中格式化逻辑侵入 command 代码的问题。

## 变更详情

### 1. AnomalyItem 数据模型重构

**Before**: 存储格式化后的字符串
```python
@dataclass
class AnomalyItem:
    time_range: str  # "2024-01-01T10:00:00 - 2024-01-01T10:00:05"
    utilization_change: str  # "15.0% -> 65.0% -> 20.0%"
```

**After**: 存储原始数据，格式由模板处理
```python
@dataclass
class AnomalyItem:
    time_range_start: str
    time_range_end: str
    prev_util: float
    curr_util: float
    next_util: float
```

### 2. PathClusterItem 数据模型重构

**Before**: 存储格式化后的百分比
```python
@dataclass
class PathClusterItem:
    ratio_pct: str  # "10.50%"
    cpu_util: str   # "127.71%"
```

**After**: 存储原始 core_sec，百分比由模板计算
```python
@dataclass
class PathClusterItem:
    core_sec: float
    total_core_sec: float  # 用于计算 ratio_pct
    duration: float        # 用于计算 cpu_util
```

### 3. 模板增强

- `TableTemplate._format_anomaly_line()`: 从原始数据格式化 time_range 和 utilization_change
- `SimpleListTemplate._format_path_cluster_line()`: 从原始 core_sec 计算并格式化百分比

### 4. Command 代码简化

**anomalies.py**: 删除 `_format_anomalies()` 函数，直接传递原始数据
**path_clusters.py**: 删除百分比计算逻辑，由模板处理

## 验证

所有命令输出格式保持不变：
- `detect-anomalies`: `SPIKE cpu=0 time=... change=15.0% -> 65.0% -> 20.0% severity=high`
- `cluster-paths`: `#1 10.67% 127.71% clone→start_thread`

## 架构收益

现在添加新命令时，如果数据需要格式化：
1. 数据模型存储原始值
2. 在 preset 中标记特殊字段（如 `_time_range`, `_ratio_pct`）
3. 在模板中添加对应的格式化逻辑

Command 代码完全不涉及格式化，真正做到"只改 preset 和模板"。
