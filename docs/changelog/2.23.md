# Changelog 2.23

## 核心变更

### CPU 利用率计算统一收口到 engine 模块

**问题:** 12个分析模块各自使用 `*_core_sec` 变量 + 手动除 duration 的方式计算 CPU 利用率，代码重复且容易出错。

**解决方案:** 在 `engine.py` 中新增统一接口，所有分析模块直接调用：

#### 新增接口

| 接口 | 用途 |
|------|------|
| `get_duration(samples)` | 获取样本时间跨度 |
| `get_process_cpu_util(samples)` | 按进程聚合 CPU 利用率 |
| `get_comm_cpu_util(samples)` | 按进程名聚合 CPU 利用率 |
| `get_symbol_cpu_util(samples)` | 按符号聚合 CPU 利用率（self/inclusive） |
| `get_core_cpu_util(samples)` | 按核心聚合 CPU 利用率 |

#### 改造的分析模块

- `process_top.py` - 使用 `get_process_cpu_util()`
- `comm_top.py` - 使用 `get_comm_cpu_util()`
- `cpu_usage.py` - 使用 `get_cpu_utilization()` + `get_core_cpu_util()`
- `clusters.py` - 使用 `get_duration()`
- `hotspots.py` - 使用 `get_symbol_cpu_util()`
- `trace.py` - 使用 `get_symbol_cpu_util()` + `get_duration()`
- `path_clusters.py` - 使用 `get_duration()`
- `anomalies.py` - 保持原样（使用 `get_sample_weight()` 进行窗口计算）
- `bottleneck.py` - 使用 `get_core_cpu_util()`
- `core_distribution.py` - 使用 `get_core_cpu_util()`
- `comm_clusters.py` - 使用 `get_comm_cpu_util()`
- `process_variety.py` - 使用 `get_duration()`

#### 代码简化效果

**改造前 (process_top.py):**
```python
process_stats = defaultdict(lambda: {
    'kernel_core_sec': 0.0, 'user_core_sec': 0.0, 'total_core_sec': 0.0
})
for s in samples:
    core_val = engine.get_sample_weight(s)
    process_stats[key]['total_core_sec'] += core_val
    ...
total_cpu_util = (stats['total_core_sec'] / duration * 100) if duration > 0 else 0
```

**改造后:**
```python
proc_util = engine.get_process_cpu_util(samples)
items = [
    ProcessItem.from_cpu_util(info['comm'], info['pid'], 
                              info['total_pct'], info['kernel_pct'])
    for info in proc_util.values()
]
```

**好处:**
1. 消除重复代码，统一计算逻辑
2. 减少出错可能性（duration 计算、百分比转换等）
3. 新增聚合维度更方便（只需在 engine 中添加）
4. 分析模块更简洁，专注于业务逻辑
