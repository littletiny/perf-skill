# Version 2.28 - 清理 core/s 痕迹，统一使用 weight 命名

## 背景

随着 engine 统一提供 CPU 利用率换算，代码中不再需要直接处理 "core/s" 概念。本次更新彻底清理了所有与 core/s 相关的变量名、注释和文档，统一使用更简洁的 "weight" 命名。

## 变更详情

### 1. 变量名统一替换

**analysis/ 目录下的所有模块**：

| 文件 | 旧变量名 | 新变量名 |
|------|---------|---------|
| `clusters.py` | `total_core_per_sec` | `total_weight` |
| | `cluster_core_sec` | `cluster_weight` |
| | `lock_func_core_sec` | `lock_func_weight` |
| `anomalies.py` | `win_core_per_sec` | `win_weight` |
| | `core_sec` (字段) | `weight` |
| `process_variety.py` | `core_sec` (字段) | `weight` |
| | `total_comm_core_sec` | `total_comm_weight` |
| `core_distribution.py` | `comm_core_sec` | `comm_weight` |
| `path_clusters.py` | `min_core_sec` | `min_weight` |
| | `_core_sec` | `_weight` |
| | `core_per_sec` | `weight` |
| | `core_sec` | `weight` |
| | `leaf_core_sec` | `leaf_weight` |
| `trace.py` | `target_core_sec` | `target_weight` |
| | `target_total_core_sec` | `target_total_weight` |

### 2. 数据模型更新

**output_models.py**:
- `PathClusterSummary.clustered_core_sec` → `clustered_weight`
- `PathClusterItem.core_sec` → `weight`
- `PathClusterItem.total_core_sec` → `total_weight`
- `WindowItem.cpu_util` → `weight`

### 3. 核心模块更新

**reliability.py**:
- 参数 `total_core_per_sec` → `total_weight`
- 指标 `total_core_seconds` → `total_weight`

**format_utils.py**:
- 函数 `format_core_sec()` → `format_weight()`

**__init__.py**:
- 导出 `format_weight` 替代 `format_core_sec`

### 4. 适配器更新

**text_output_adapter.py**:
- `_format_path_cluster_line()`: 使用 `weight` / `total_weight`
- `_format_window_line()`: 使用 `weight` 替代 `core_sec`

### 5. 注释清理

清理了所有模块 docstring 中关于 "core/s" 的冗余说明：
- "基于 core/s（CPU 利用率）而非记录数统计"
- "数据已按 1 秒聚合，样本数量无参考价值，分析基于 core/s 值"
- "注意：...分析基于 core/s 值"

## 保留的 core/s 引用

以下情况保留原有命名（属于内部实现细节）：

1. **engine.py**: 
   - `get_total_core_per_sec()` 函数名（API 兼容性）
   - `core_per_sec` 样本字段（数据结构）
   - `_has_core_per_sec` 检测标志（格式识别）
   - `get_user_kernel_core_per_sec()` 函数名

2. **数据文件解析**: `'core/s:'` 字符串识别（SPEAR 格式检测）

## 验证

所有命令功能保持不变，输出格式不变：

```bash
# 热点分析
$ python perf_expert.py get-hotspots --data case_test.data --top-n 3
#1 established_get_first 12.80% 20.73%

# 符号聚类
$ python perf_expert.py cluster-symbols --data case_test.data
EVENT_LOCK_CONTENTION 7.93%

# 路径聚类
$ python perf_expert.py cluster-paths --data case_test.data --top-n 3
#1 10.67% 127.71% clone→start_thread
```

## 架构收益

1. **命名统一**: 所有分析模块使用 `weight` 表示样本权重，不再暴露 core/s 概念
2. **职责清晰**: engine 负责换算，analysis 只关心权重累加
3. **代码简洁**: 删除了大量解释 core/s 的冗余注释
