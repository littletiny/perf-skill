# Version 2.22

## 新增功能

### 截断提示
所有 list 输出接口现在支持截断提示。当实际结果数量超过 `--top-n` 限制时，会显示提示：

```
# ... 673 more items (use --top-n to show more)
```

### 受影响的命令
- `get-hotspots`
- `cluster-symbols`
- `get-process-top`
- `get-comm-top`
- `cluster-paths`
- `count-process-variety`
- `find-callers`

## 技术变更
- 修改 output_models.py，为各 summary 添加 shown_* 字段记录显示数量
- 修改 text_output_adapter.py，添加 `_check_truncation` 方法检测截断
- 各 analysis 模块重新添加 summary 到输出

## 示例
```bash
$ python perf_expert.py get-hotspots --data perf.data
# index,funcname,self,inclusive
#1 established_get_first 12.80% 1.73%
...
#10 do_user_addr_fault 1.22% 0.51%
# ... 673 more items (use --top-n to show more)
```
