# Version 2.29 - 优化 AGENTS.md 结构与文档导航

## 背景

AGENTS.md 作为开发指南，部分内容存在冗余和结构不够清晰的问题。本次更新重写整个文档，优化信息组织方式，补充缺失的设计文档和 core 模块导航。

## 变更详情

### 1. AGENTS.md 重写

**精简冗余内容：**
- 删除重复的强调语句（如两次重复的"修改代码之前先确认方案"）
- 简化目录结构展示，不再逐行列出 analysis/ 下每个文件
- 删除「已移除的子命令」历史记录

**核心原则合并：**
- 将「重要」章节的 7 条零散规则合并为 4 条简洁原则
- 删除重复的「数据文件规范」说明

### 2. 设计文档导航完善

**补充 docs/ 下所有设计文档：**

| 文档 | 概述 |
|------|------|
| `design-rationale-trace-v1.md` | Trace v1.0 设计意图 - 基于 netstat 案例的问题追踪机制 |
| `design-rationale-trace-v2.md` | Trace v2.0 演进设计 - 从手动记录到全自动 Tracing |
| `output-format-spec.md` | 工具输出格式规范 - 统一 JSON 标准（_risk、时间格式等） |
| `output-system.md` | Output System 快速参考 - 统一数据结构与代码复用 |
| `trace-interface.md` | Trace 接口设计 - CLI 接口与技术规格 |

**新增「设计文档维护规范」：**
- 要求每次新增设计文档必须同步更新目录结构章节
- 规定概述格式：`<文件名> - <一句话描述核心内容>`

### 3. core 模块导航补充

**完整列出 scripts/perf_toolkit/core/ 下所有基础库：**

| 文件 | 用途 |
|------|------|
| `engine.py` | 核心引擎（PerfExpertEngine）|
| `reliability.py` | 样本可靠性评估 |
| `symbol.py` | 符号处理 |
| `trace.py` | 诊断追踪（LiveDoc）|
| `risk_mixin.py` | 风险信息标准化 |
| `format_utils.py` | 时间/格式工具 |
| `output_models.py` | 数据模型定义 |
| `output_adapter.py` | JSON 输出转换 |
| `text_output_adapter.py` | 文本输出转换 |
| `output_builder.py` | 输出构建器 |
| `display_presets.py` | 显示配置预设 |

### 4. 新增开发规范

**章节编号规范：**
- 禁止使用数字编号（如 `### 1. xxx`），避免章节变动时连锁修改
- 统一使用标题文字本身作为标识

**命令与文档同步规范：**
- 修改或新增 CLI 命令时，必须同步更新 SKILL.md 和 references/tools.md
- 保持命令参数、输出格式与实际代码一致

### 5. 子命令路径完善

子命令清单中的「所在模块」改为「所在文件」，并补全完整相对路径：
- 之前：`bottleneck.py`
- 之后：`scripts/perf_toolkit/analysis/bottleneck.py`

## 架构收益

1. **信息密度提升**：文件从约 6500 字节精简至约 5000 字节
2. **导航效率提升**：core/ 目录文件一目了然，便于快速定位
3. **维护成本降低**：无编号章节避免连锁改动，新增规范防止文档遗漏
