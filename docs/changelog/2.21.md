# Version 2.21

## 主要变更

### 1. 统一列表输出格式
- 所有列表输出添加描述元信息的 format header
- 移除概述 header（如 [total_hotspots=10, duration=60s]）
- 列表行去掉 `key=` 前缀，直接显示值

### 2. 各子命令输出优化

#### get-hotspots
- 默认按 self 从大到小排列
- format header: `# index,funcname,self,inclusive`

#### get-process-top
- format header: `# comm(pid) (usr+sys)/sys`
- 显示 CPU 利用率百分比而非 core/s

#### cluster-symbols
- format header: `# type,percent,cpu_util`
- 移除 core_sec 列

#### cluster-comm / get-comm-top
- 过滤 normal event，只显示异常事件
- format header: `# comm,pids,cpu_util,event`
- event 格式简化为: `<HIGH_KERNEL_RATIO:94.9%>`

#### count-process-variety
- 过滤 normal behavior
- 只显示 pid >= 10 的进程风暴
- format header: `# PROCESS_STORM: comm,pids,cpu_util`

#### analyze-core-distribution
- 只显示 saturated 核心（CPU > 90%）
- format header: `# SATURATED_CORES: index,cpu_id,(usr+sys)/sys`

#### find-callers
- 箭头改为 `<-` 表示被调用关系
- 显示调用链占总样本的比例（而非占目标函数比例）
- 修复 `--auto-target` 百分比超 100% 的 bug

### 3. show-cpu-usage 增强
- 内嵌单核 sys 利用率检测（>70% 告警）
- 输出高 sys 核心列表

### 4. detect-anomalies 优化
- 默认窗口大小改为 1 秒

### 5. 所有 list 接口支持 topN
- 默认 topN = 10
- 支持的命令: cluster-symbols, analyze-core-distribution, find-callers

### 6. find-callers 参数统一
- 移除 `--auto-target-top-n`
- 统一使用 `--top-n`（默认 10）

## 修复
- 修复 find-callers 等子命令的输出格式问题（字符拆分 bug）
- 修复 count-process-variety 单进程误判为 process_storm 的问题
