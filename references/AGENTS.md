# references/ - 参考文档

## 目录简介

交付给用户的使用文档，包含工具说明、方法论、数据格式等。

## 重要原则

此目录只包含与使用相关的信息。内部设计讨论、实现细节等应放在 `docs/` 目录。

## 文档清单

| 文件 | 说明 |
|------|------|
| `cli-commands.md` | CLI 命令参考 |
| `tools.md` | 工具命令清单 |
| `methodology.md` | 分析方法论 |
| `data-format.md` | 输入数据格式规范 |
| `templates.md` | 文档模板 |
| `trace-external.md` | 外部追踪集成 |

## 使用建议

- **添加 CLI 命令** → 更新 `cli-commands.md`
- **修改数据格式** → 更新 `data-format.md`
- **新分析模式** → 更新 `methodology.md`
